# Infinite Runner

A small, asset-free 2D endless runner made in Unity 6. Open the `Infinate`
folder in Unity Hub, load `Assets/Scenes/SampleScene.unity`, and press Play.

## Controls

- Jump: Space, W, Up Arrow, left click, or tap
- Restart after a collision: R, Space, click, tap, or the Run Again button

The game gets faster over time and saves the best score locally.
